How to use the Voxel Editor

This tool allows you to convert an image into a 3D voxel model and edit it. You can also upload pre-made JSON models.

Upload an Image: Use the "Convert Image to Voxel" button. The image will be converted slice by slice into a 3D model. You can adjust the "Vertical Voxels" to control the model's depth.

Undo/Redo: Any change you make to the model can be undone or redone using the dedicated buttons.

Delete Menu:

  • Background: Removes all voxels with the same color as the edges of the source image.
  • Single Delete: Click on any voxel in the 3D scene to instantly remove it.
  • Continuous Delete: Click and hold your mouse on the model to delete voxels as you move your cursor.
  • Box Area: Click two points on the grid to define a rectangular area. All voxels within this area will be removed. This tool stays active until you click the button again.
  • Lasso: Click multiple points to define a custom shape. Click the 'Finish Lasso' button to delete all voxels inside.
  • By Color: Use the color picker to select a color and the tolerance slider to define how close other voxel colors must be to be deleted.
  • Cut Model: Click on a voxel and the tool will remove all voxels either above or below the horizontal plane of the selected voxel.

Thumbnail: Click on the small image thumbnail to view the original source image in a larger, pop-up window.
